# Sprint 0 Assignment Packets

Use these packets for the first two Dev 1 assignments. They are ready to hand to
junior research agents.

## R-002 Component And Style Inventory

```text
Assignment: Complete the component and style inventory.
Role: Dev 1 Research Agent

Primary file:
visual_overhaul_project/02_research_tasks/R-002_component_style_inventory.md

Read these context summaries first:
visual_overhaul_project/01_context/summaries/current_visual_state_seed.md
visual_overhaul_project/01_context/summaries/gui_architecture_summary.md
visual_overhaul_project/01_context/summaries/screen_inventory.md

Do this:
Inspect the required GUI/config files, run the listed style searches, and write
visual_overhaul_project/01_context/summaries/style_inventory.md.

Do not do this:
Do not change application code, introduce shared style helpers, decide the final
foundation, or redesign screens.

Expected output:
style_inventory.md with observed constants, inline style inventory, repeated
visual patterns, candidate shared tokens, risks, recommendations, and Dev 2
Quick Start notes.

Required verification:
Documentation review only. Confirm context_index.md and status_board.md are
updated and the summary passes the Definition of Ready.

Handoff location:
Use visual_overhaul_project/06_handoffs/handoff_template.md.

Notes:
List search terms used and any GUI files not inspected.
```

## R-001 Baseline Visual Audit

```text
Assignment: Complete the baseline visual audit.
Role: Dev 1 Research Agent

Primary file:
visual_overhaul_project/02_research_tasks/R-001_baseline_visual_audit.md

Read these context summaries first:
visual_overhaul_project/01_context/summaries/gui_architecture_summary.md
visual_overhaul_project/01_context/summaries/screen_inventory.md

Also use:
visual_overhaul_project/06_handoffs/screenshot_checklist.md

Do this:
Start the app, prepare realistic local test data if needed, capture the required
light/dark screenshots, and write
visual_overhaul_project/01_context/summaries/baseline_visual_audit.md.

Do not do this:
Do not change application code, fix UI issues, make visual foundation decisions,
or redesign screens.

Expected output:
baseline_visual_audit.md with screenshot inventory, app-wide findings,
per-screen findings, light/dark differences, missing states, foundation-relevant
priorities, and Dev 2 Quick Start notes.

Required verification:
Documentation and screenshot review only. Confirm context_index.md and
status_board.md are updated and the summary passes the Definition of Ready.

Handoff location:
Use visual_overhaul_project/06_handoffs/handoff_template.md.

Notes:
List screenshot folders, local data setup, missing states, and runtime blockers.
```
